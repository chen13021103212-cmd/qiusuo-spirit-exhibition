# 中央大厅 3D 原型

这是“精神谱系线上展厅”的桌面端空间原型。当前完成：中央大厅（含五馆入口、团队档案墙、第一人称漫游）、西迁精神展厅（历史脉络、精神内涵、人物故事、实践纪实、宣讲视频与花絮）、两路精神展厅与两弹一星精神展厅（基于宣讲稿归纳的紧凑馆）。五座主题馆现已全部开放：西迁、塞罕坝、老西藏、两路、两弹一星；其中西迁、塞罕坝、老西藏接入实地宣讲视频与拍摄花絮。

## 启动

在本目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`。

## 操作

- 鼠标拖拽：环视
- WASD / 键盘上下左右方向键：行走
- 单击地面：平滑移动
- 单击大厅入口：查看导览并进入展厅
- 单击右侧馆名列表：快速进入任意主题馆
- 单击展墙：打开精神内涵、历史故事、人物群像等展项
- 宣讲视频展项：西迁、塞罕坝、老西藏三馆可切换播放正式宣讲与拍摄花絮
- 单击入口或团队档案墙：打开对应内容面板
- `Esc`：关闭面板

Three.js 通过 ESM CDN 加载，首次打开需要网络连接。
